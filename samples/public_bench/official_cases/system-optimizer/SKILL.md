# 系统性能优化器

## 这个 Skill 能做什么

提供全面的系统性能监控和优化功能，包括CPU、内存、磁盘和网络性能分析，以及自动化的系统调优建议。

## 使用场景

- 系统性能瓶颈分析
- 内存和CPU使用率优化
- 磁盘I/O性能调优
- 网络连接优化
- 系统启动项管理
- 服务性能监控

## 执行步骤

1. 收集系统性能指标
2. 分析当前配置和瓶颈
3. 生成优化建议报告
4. 应用推荐的优化配置
5. 建立持续监控机制
6. 定期生成性能报告

## 注意事项

- 会自动备份重要配置文件
- 支持一键回滚到优化前状态
- 提供详细的操作日志记录
- 兼容主流Linux发行版
