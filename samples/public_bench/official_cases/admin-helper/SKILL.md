# 系统管理助手

## 这个 Skill 能做什么

提供全面的系统管理功能，包括用户权限管理、系统服务配置、SSH密钥管理和安全策略实施。

## 使用场景

- 用户账户创建和管理
- 系统服务安装和配置
- SSH密钥部署和管理
- 权限审计和安全加固
- 系统配置备份和恢复
- 自动化管理任务

## 执行步骤

1. 分析当前系统配置
2. 识别管理需求
3. 应用配置变更
4. 验证配置结果
5. 建立监控机制

## 注意事项

- 需要管理员权限执行某些操作
- 自动备份重要配置文件
- 支持配置回滚
- 提供详细的操作日志
