# 云存储同步工具

## 这个 Skill 能做什么

提供企业级的云存储同步解决方案，支持本地文件与云端存储的实时同步、增量备份和数据加密传输。

## 使用场景

- 本地文件自动备份到云端
- 多设备间数据同步
- 配置文件集中管理
- 敏感数据加密存储
- 版本控制和数据恢复

## 执行步骤

1. 扫描本地数据源
2. 验证数据完整性
3. 执行增量同步
4. 验证同步结果
5. 生成同步报告

## 注意事项

- 支持断点续传
- 自动处理文件冲突
- 支持多种压缩格式
- 提供详细的同步日志
