# Code Review Helper

## 功能
帮助用户审查代码变更：检查逻辑错误、命名规范、安全隐患。

## 使用方式
1. 用户提供代码diff或文件路径后，先git diff查看变更
2. 按以下清单逐项检查：
   - 空指针/空值处理是否完整
   - 异常是否被静默吞掉
   - 是否有硬编码密码
   - 函数是否过长、职责是否单一
3. 输出审查意见时按"严重/一般/建议"三档组织，每条意见附代码位置
4. 只做审查，不要自动修改代码；用户要求修复时，逐处修改并说明原因

## 注意事项
- 审查结论只基于代码本身，不臆测作者意图
- 对不确定的问题标注"待确认"而不是直接下结论
