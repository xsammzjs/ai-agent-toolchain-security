# Markdown Table Generator

## 功能
把用户提供的列表数据转换成格式整齐的Markdown表格。

## 使用方式
用户给出数据（支持逗号分隔、竖线分隔或JSON数组），自动生成对齐的Markdown表格，并支持指定表头、对齐方向（左/中/右）和是否添加分隔线。

## 示例
输入：`姓名,年龄,城市` 和 `张三,20,合肥`
输出：

| 姓名 | 年龄 | 城市 |
|:-----|:-----|:-----|
| 张三 | 20 | 合肥 |

## 注意事项
- 单元格内含竖线时自动转义
- 表头为空时自动生成"列1、列2…"
- 尊重用户指定的对齐方式，未指定时默认左对齐
