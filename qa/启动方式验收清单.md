## 0. 前置环境事实（实测得出，不是假设）

这些是本机实测确认的**环境事实**，写在这里是为了让后续验收的人不再重复踩坑。

| 事实 | 影响 |
|---|---|
| 本机设了 `http_proxy` / `https_proxy` | 直接 `curl http://127.0.0.1:8501` 会**超时**。必须 `--noproxy '*'` 或用 `ProxyHandler({})` 清空代理 |
| Streamlit 1.60 的 `_bind_socket` **总是**设 `SO_REUSEADDR` | Windows 上后启动者会**抢占**已监听端口。所以「端口是否空闲」**不能**用带 `SO_REUSEADDR` 的 bind 探测 |
| Streamlit 冷启动 **10-30 秒** | 所有「等服务起来」的断言必须**轮询 + 超时**，固定 sleep 会误判 |
| `netstat` 输出是 **GBK** 编码 | subprocess 捕获必须 `decode("gbk")` |
| `cmd.exe` 遇到 **UTF-8 BOM** 会报 `'xxx' 不是内部或外部命令` | `.bat` 文件**绝不能带 BOM** |
| `TaskStop` 只杀 shell，不杀派生的 python 子进程 | 收尾要用 `netstat` 找 PID 再 `taskkill` |
| 项目 `.venv` 是 **Python 3.13.14**，Streamlit **1.60.0** | `runtime.txt` 写的 3.12，与实际不符（另见已知问题） |

## 1. 一键双击可用

- [ ] **A1 `.bat` 无 UTF-8 BOM，且换行符是 CRLF**
  - 验证：`python -c "d=open('快速运行.bat','rb').read(); print(d[:3], d.count(b'\r\n'), d.count(b'\n')-d.count(b'\r\n'))"`
  - 判据：BOM 为 `False`（`b'\xef\xbb\xbf'`）；裸 LF 数为 0
  - 后果：BOM 会让 cmd.exe 第一行直接报语法错（**已实测复现**）
- [ ] **A2 `.bat` 能被 `cmd.exe` 正常解析**
  - 验证：跑净化副本（把 `pause` / 拉服务换成 echo），`cmd /c probe.bat`
  - 判据：输出里没有「不是内部或外部命令」「命令语法不正确」；且能跑到启动阶段
- [ ] **A3 `.bat` 有 `chcp 65001`**
  - 验证：`grep -i "chcp 65001" 快速运行.bat`
  - 判据：能匹配到。否则中文提示在 cmd 控制台是乱码
- [ ] **不会闪退**：双击后窗口**不消失**
  - 验证：`cmd /c 快速运行.bat --check --no-browser` 观察窗口行为
  - 判据：正常结束时打印「服务已停止」并 `pause` 等待，窗口不闪
- [ ] **中文不乱码**
  - 验证：同上，看控制台输出
  - 判据：`AI 技能与依赖漏洞检测平台` 正常显示，非 `????`

## 3. 端口冲突处理

- [ ] **C1 端口占用探测准确**
  - 验证：占住测试端口 8765，再跑 `port_is_free(8765,'127.0.0.1')`
  - 判据：返回 `BUSY`（**不能**返回空闲）
  - 原因：探测 bind **不带** `SO_REUSEADDR`，否则 Windows 上会误判空闲
- [ ] **C2 端口被占时自动避让，且提示地址 == 实际端口**
  - 验证：占住 8765 → `start.py --port 8765` → 解析输出的访问端口 → 轮询 health
  - 判据：提示端口 ≠ 8765；该端口有监听；`/_stcore/health` 返回 `ok`
  - **这是最常见的 bug**：避让到 8502 却仍提示 8501

## 9. `.bat` 与 `start.py` 的一致性

- [ ] **G1 `.bat` 委托给 `start.py`**（单一启动逻辑源）
  - 判据：`.bat` 里出现 `start.py`
  - 原因：两套并行逻辑必然漂移 —— 端口避让、浏览器、health 检查会各说各话
- [ ] **G2 `--check` 不打开浏览器**
  - 判据：`BROWSER=echo` 下捕获不到 `http://localhost:` 形式的 URL
  - 原因：`--check` 承诺「只做环境自检」，不该弹浏览器
- [ ] **G3 `.bat` 正确传递 `start.py` 的退出码**
  - 验证：真实 `.bat` 跑 `--check --no-browser`
  - 判据：退出码 0；输出无「[启动失败]」
  - 原因：`setlocal disabledelayedexpansion` + `%ERRORLEVEL%` 会取到**空串**，
    导致成功也报失败（真实踩过的坑）
- [ ] **G4 `start.py` 接受 `.bat` 传的 `--ask-port`**
  - 验证：`start.py --ask-port --check`
  - 判据：退出码 0，无 `unrecognized arguments` / `invalid choice`
