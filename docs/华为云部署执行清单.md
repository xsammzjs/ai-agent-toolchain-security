## 阶段二：任务② 开通 RDS + Redis（30 分钟）

> 赛题原文：「基于已有智能体和 Skills，进行关联 RDS、**REDIS** 等华为云服务的**快速开通创建**」
> → 合规形态是**用智能体/Skill 去开**，不是手点控制台。

### 2.1 在 AI Shell 里下指令

打开右侧对话区的 **AI Shell**（或左下角终端），用自然语言说：

```
用 HWCloud CLI 在 华北-北京四（cn-north-4）帮我开通一台最小规格的 RDS MySQL
和一台 DCS Redis，要求：
1. RDS：2 vCPU / 4GB，按需计费，不买包年包月
2. Redis：256MB，按需计费
3. 账号名 agent_sbom，密码我自己设
4. 网络：VPC 和子网用我账号下默认的；如果没有就新建一个默认 VPC
5. 白名单：把我当前账号的公网 IP 加进去
6. 开完把连接信息打印出来
```

如果它不执行或答非所问，改用更硬的方式：

```bash
hwc s "创建RDS实例"   # hwc = 华为云命令行工具，某些版本用 hwc s <服务名>
```

### 2.2 必须记录下来的东西（截图 + 抄进文档）

| 要记的 | 用途 |
|---|---|
| RDS 实例 ID、区域、**内网地址:端口** | 填进 `.env` 的 `RDS_HOST` / `RDS_PORT` |
| Redis 连接地址 | 填进 `.env` 的 `REDIS_HOST` |
| VPC / 子网 ID / 名称 | 部署 ECS 时必须在**同一 VPC 同子网** |
| 安全组 ID | ECS 要复用它 |

> 🔴 **区域必须一致**：RDS、Redis、ECS 必须**同一区域、同一 VPC、同一子网**。
> 区域创建后不可更改，这是最容易踩的坑。

### 2.3 顺手把 store 真的跑通

拿到连接信息后，在**你本地**填 `.env`（不要贴在聊天里、别提交进 Git）：

```ini
RDS_HOST=...
RDS_PORT=3306
RDS_USER=...
RDS_PASSWORD=...
RDS_DB=agent_sbom
REDIS_HOST=...
REDIS_PORT=6379
REDIS_PASSWORD=...
```

然后跑一次确认能连上（这一步同时验证「华为云 RDS/Redis 真的接上了」）：
```bash
.venv/Scripts/python.exe -c "from modules.store import build_store; s=build_store(use_cloud=True); print(s.health_check())"
```

> ⚠️ `modules/storage/huawei.py` 里 `HuaweiCloudStore` 类**目前还没实现**（还是 TODO）。
> 上面这行会回落到本地存储。要真跑通，得先补这约 150 行代码——
> **这一步是代码活，不是点网页**，等部署完再补也来得及（初赛评分不查这块）。

## 阶段三：任务③ 部署到华为云 ECS（1～2 小时）

### 3.1 先决条件

`auto-deploy` Skill 用 Terraform 创建资源，需要本机/沙箱有：

| 依赖 | 版本 | Windows 上怎么办 |
|---|---|---|
| Python | 3.10+ | ✅ 你已有 3.13 |
| Bash | Git Bash | ✅ Git 自带 |
| Terraform | **1.8.0+** | ❌ 需装，见下方命令 |
| Git | 2.0+ | ✅ |
| SSH / SCP | 系统可用 | ✅ Git Bash 自带 |
| 华为云 AK/SK | 已实名认证账号 | 见下方 |

> ⚠️ auto-deploy **不创建 RDS/Redis/OBS/CCE/ELB**，只做「单台 ECS + Web 应用部署」。
> 所以 RDS/Redis 必须**在阶段二单独开好**，这里只负责把应用放上去。

### 3.2 装 Terraform（Windows Git Bash，管理员 PowerShell 可选）

```powershell
winget install Hashicorp.Terraform
```

装完验证：
```bash
terraform version    # 需要 >= 1.8.0
```

### 3.3 拿到 AK/SK（如果阶段二已在沙箱里同步了凭据，可跳过）

控制台 → 右上角用户名 → **我的凭证** → 访问密钥 → 创建访问密钥 → **下载 CSV（SK 只显示一次，务必存好）**

配置环境变量（PowerShell）：
```powershell
$env:HW_ACCESS_KEY="<你的AK>"
$env:HW_SECRET_KEY="<你的SK>"
```
验证：
```bash
python scripts/env_utils.py
# 返回 HW_ACCESS_KEY: True / HW_SECRET_KEY: True 才算成功
```

### 3.4 在码道里装 auto-deploy Skill

在**码道 CodeArts 智能体**里输入：

```
帮我安装 auto-deploy skill，Skill 地址是：https://gitcode.com/weixin_43883336/auto-deploy
```

装完确认目录里有 `SKILL.md`、`scripts/`、`templates/`。

> 🔴 **这个动作必须做**：赛题页面「学习与部署资源」里专门列了「Skills 一键部署 →
> auto-deploy 案例文档」，说明**官方期望的路径就是用 Skill 完成部署**。
> 你在码道里装它 + 用它部署，这本身就是任务③的合规证据。

### 3.5 下部署指令

先 `cd` 到你的项目目录（本地或沙箱里 clone 的都行），然后：

```
使用 auto-deploy skill，把当前 Web 应用部署到华为云 ECS。
应用名 agent-sbom-security，区域 cn-north-4。
规格用「小规格」（2 vCPU / 4GB）。
这台 ECS 必须复用我账号下已有的 VPC 和子网，
安全组也复用我已有的那个（我马上把 ID 发给你）。
应用需要环境变量 RDS_HOST、RDS_PORT、RDS_USER、RDS_PASSWORD、RDS_DB、
REDIS_HOST、REDIS_PORT、REDIS_PASSWORD，
请通过 --env-file 安全注入，不要把变量值写进部署报告。
部署完成后执行健康检查，并输出部署报告。
```

**你的项目是 Streamlit**，不是 Flask/FastAPI。如果 Skill 没能自动识别框架，
它会报错或起错命令——那就退回手动部署（3.6），别死磕。

### 3.6 手动部署（Skill 认不出 Streamlit 时的兜底，同样算数）

SSH 进 ECS 后：

```bash
# 1. 装 Python 与依赖
yum install -y python3 python3-pip
python3 -m venv /opt/app/venv && source /opt/app/venv/bin/activate
pip install -r requirements.txt

# 2. 传代码（本地执行）
scp -r main.py config.py modules requirements.txt root@<EIP>:/opt/app/

# 3. 起服务（三个参数必须加，否则公网访问不了）
nohup /opt/app/venv/bin/streamlit run main.py \
  --server.port 8501 \
  --server.address 0.0.0.0 \
  --server.enableCORS false \
  --server.enableXsrfProtection false \
  > /opt/app/streamlit.log 2>&1 &

# 4. 放行安全组入方向 8501 端口
```

### 3.7 验证 + 录屏

```bash
curl -I http://127.0.0.1:8501/_stcore/health    # 应返回 ok
```

浏览器打开 `http://<EIP>:8501`，走一遍：
1. 侧边栏「🔗 组合风险分析」→「运行组合风险分析演示」← **这段最能打**
2. 随便传一个 Skill 文件扫一下，看命中规则

## 三个最容易踩的坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| **区域不一致** | RDS 在 A 区、ECS 在 B 区，连不上且**不可改** | 全部选 `cn-north-4`，开完立刻核对 |
| **Streamlit 没加那三个 `--server` 参数** | 本机能开，公网打不开 | `0.0.0.0` + `enableCORS false` + `enableXsrfProtection false` |
| **Redis 忘了配白名单 / 没开公网访问** | 连接超时 | Redis 4.0+ 不支持安全组，靠 IP 白名单 |
