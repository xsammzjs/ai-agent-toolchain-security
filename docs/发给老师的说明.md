## 三、老师可能问的六个问题

### Q1「跟市面上工具有什么区别？」

```
市面上的 Snyk、Dependabot、pip-audit、Trivy
  → 只查"软件依赖包的已知漏洞"

我们：查 AI Agent 的技能包（这是新东西，传统工具不管）
     并且能查"多个技能组合起来的攻击链"
```

### Q2「误报 2% 还能再降吗？」

```
技术上能，但我们选择不降。
一味压误报会引入漏报，那才是安全工具的失效。
判据是：宁可不报，不可乱报。
（我们真的删掉了一条规则，即使它能让指标更好看）
```

### Q3「代码是你写的吗？」

```
项目架构和规则设计是我做的，AI 辅助编码。
代码 6500 行，151 条自动化测试，
每条检出结论都能定位到具体行号，当场可验证。
```

### Q4「为什么用华为云？」

```
赛题1 明确要求使用华为的 AI 技术，
开发工具里写明了 CodeArts（必选）。
我们接入了 CodeArts 并实际用于规则审计。
```

### Q5「AI 会不会乱说？」

```
不会让 AI 参与判定。
代码里有强制约束 assert_ai_not_judging()，
AI 只能做汇总建议，改不了检测结论。
而且没配大模型时，它会明确显示"未调用大模型"，不伪装。
```
