## 第 3 步：把程序搬到华为云

买 ECS/Flexus L（轻量，便宜），**必须绑 EIP（公网 IP）**，安全组放行 22 和 8501，然后：

```bash
git clone <你的仓库> && cd ai-agent-toolchain-security
sudo apt install -y python3.10-venv && python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pip install pymysql redis
cp .env.example .env && vi .env      # 填 RDS_*/REDIS_*/MAAS_*
nohup .venv/bin/streamlit run main.py \
  --server.port 8501 --server.address 0.0.0.0 \
  --server.enableCORS false --server.enableXsrfProtection false \
  > streamlit.log 2>&1 &
```

**那三个 `--server` 参数必须加**，不加外部访问不了。
