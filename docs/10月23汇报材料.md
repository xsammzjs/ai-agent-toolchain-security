## 二、10 分钟汇报怎么排（照着念就行）

### 第 1 部分｜我们做了什么（2 分钟）

**开场一句话**：

> 「我们做的是 **AI Agent 技能包的安全检测**——
> 现在 AI 助手会安装各种 Skill，这些 Skill 就像软件包一样，
> 但恶意 Skill 已经在真实世界里造成了大规模攻击。
> 我们做了一个工具，能在安装前把恶意 Skill 检测出来。」

**关键数字（背下来，评委最爱问）**：

| 数字 | 含义 |
|---|---|
| **29条** | 检测规则数，覆盖 8 类威胁 |
| **100%** | 恶意样本检出率 |
| **2.0%** | 真实良性样本误报率（优化前 58.6%） |
| **33ms** | 单次扫描耗时 |
| **107个** | 真实样本测试语料 |

### 第 2 部分｜为什么这个东西有价值（2 分钟）

**讲一个真实案例**（老师能听懂的版本）：

> 「2026 年有 1,184 个恶意 Skill 被安装了 24.7 万次。
> 传统工具能查出『这个文件有危险』，
> 但我们的工具能查出『这三个看起来正常的技能，合在一起会偷你的密钥』。」

**这就是我们的核心创新：跨技能攻击链。**

```
传统工具：  Skill A有风险 ✓    Skill B 有风险 ✓    Skill C 有风险 ✓
                        ↓
              但它们合起来能干什么？  ← 传统工具答不上来

我们：    能画出「谁 调用 谁」的图，搜索出完整攻击路径
```

### 第 3 部分｜创新点（2 分钟）

**一句话概括**：

> 「传统工具做**单点检测**，我们做**关联分析**——
> 像杀毒软件查病毒 vs 防火墙查攻击链的区别。」

**支撑证据（有时间就讲，没时间跳过）**：

> 「我们查过 2026 年全国大学生信息安全竞赛 45 个一等奖作品，
> 有 5 个是 Agent 安全方向的，**全部是单点检测，没有一个做跨技能关联**。」

## 三、老师可能问的问题（提前准备）

### Q1「这个东西跟市面上的工具有什么区别？」

```
市面上：Snyk、Dependabot、pip-audit、Trivy —— 都只查依赖包的已知漏洞
我们：查 AI Agent 的技能包（这是新东西，传统工具不管）
     并且能查「多个技能组合起来的攻击链」，这是全球范围内没人做的
```

### Q2「误报率 2%，能再降吗？」

```
可以，但我们选择不再降。
原因：误报和漏报要平衡。我们的判据是「宁可不报，不可乱报」——
     一味压低误报会引入漏报，那才是安全工具的失效。
我们删掉了一条无法避免误报的规则，即使它能让指标更好看。
```

### Q3「代码是你写的吗？」

```
项目架构和规则设计是我做的，AI 辅助编码。
代码 7000 多行，32 条检测规则，
每条规则都能给出「哪个文件第几行命中了什么」，可当场核验。
151 条自动化测试全部通过。
```

**如果被追问具体实现**（比如让你解释某条正则）：
- 说得出就说
- 说不出就说「这条规则的具体正则我需要回去查，
  但设计意图是XXX，因为要防的是YYY」
- **别硬编**
