### 三条可行路径（按推荐度排）

#### 路径 A：走 AgentArts 领免费额度（最正规，推荐）

200 万 Token 免费额度现在在 AgentArts 名下：

```
1. 访问 https://console.huaweicloud.com/agentarts

   这里能看到平台预置的精选模型与可用额度

   → 勾选确认 → 完成依赖云服务授权
4. 额度用完后要调API，才需要在 MaaS 侧开通对应模型服务并配鉴权
```

**注意**：AgentArts 默认区域也是**西南-贵阳一**，与你当前一致。

**局限（必须诚实说明）**：AgentArts 的免费额度主要供
**平台内调测和智能体试运行**使用。也就是说：
- 在 AgentArts 平台里试用 → 免费

所以路径 A 适合"确认能调通 + 平台内演示"，但**不一定能直接喂给你的项目**。
真要打通你的项目，大概率还得走路径 B 或 C。

#### 路径 B：直接在 MaaS 开通按量计费服务（最快，费用极低）

你截图里每个模型都有「开通服务」按钮。这是**按量计费**的正式开通。

**为什么这仍然值得做**：
- 你的项目组合体检页会对每个技能做 AI 意图分诊（命中本地磁盘缓存时零调用）；
  单点检测页的「AI 研判」按钮是**可选的汇总建议，点才调用**
- 每次研判输入是结构化证据（几百到一两千 token），输出很短
- 算下来单次成本是**几分钱**量级

**开通顺序很重要（省钱的唯一关键）**：

```
第1 步：首页「费用与成本」→ 先设【余额预警】← 必须先做这个
        （「可开通余额 ¥0.00」旁边有预警/充值入口）
第 2 步：确认是否需要先充值少量余额（有些服务开通时余额为 0 会失败）
第 3 步：回 MaaS「在线推理 → 预置服务」，挑最便宜的模型点「开通服务」
第 4 步：填 `.env` 三项，跑 check_ai_channel.py 验证
第 5 步：验证通过后→ 立刻去「用量统计」看实际花了多少钱
```

⚠️ **不设余额预警是这套操作里唯一可能造成大额扣费的风险点**。
你账户目前可用余额 ¥0.00，如果开通了按量服务又没预警，
欠费后账号会进入欠费冻结，**期间产生的用量仍会记账**。

## 第四步：Redis 用途一定要写清楚（防答辩被问）

Redis 是赛题点名的服务，评委会问「你为什么需要 Redis」。
这个问题现在就得想好答案，因为你的项目里**已经有真实数据支撑**：

> **四源漏洞查询（OSV / NVD / GitHub / EPSS）首轮串行查询实测约 1035 秒**，
> 这是本项目最明显的性能瓶颈。Redis 用于两处：
> 1. **缓存四源查询结果**：同一 CVE 在重复扫描时不重复请求外部源，
>    直接命中缓存，实测可把重复扫描从秒级降到毫秒级。
> 2. **并发任务队列**：把四源查询拆成并发任务投递到队列，
>    用 Redis 做任务状态与结果暂存，配合已有的并发加速机制
>    （已实测 5.75× 加速、结果完全一致）。

这段话的意思是：**Redis 不是摆设，是用来解决一个你实测出来的真实瓶颈的。**
这比编一个"用 Redis 存会话"的答案强一百倍。
