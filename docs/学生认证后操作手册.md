## 先搞清楚一件事：学生认证给你的是什么

这一点很关键，混淆了会白忙。

| 你拿到的 | 是什么 | 能干什么 | 不能干什么 |
|---|---|---|---|
| **码道 CodeArts 4000 积分**（90 天有效，2026-12-31 前领） | CodeArts 智能体的调用额度 | 用 AI 审计代码、继续做规则优化 | **不能**开通 RDS / Redis / ECS |
| 华为云账号实名认证 | 开通所有云服务的资格 | 可创建资源、可用免费试用 | 本身不送资源 |

**结论：学生认证解决的是「CodeArts 积分」，不是「云资源券」。**
云资源（RDS/Redis/ECS）要么用**免费试用额度**，要么等**比赛代金券**。
好消息是免费试用这条路是通的，见本文第三节。

> ⚠️ 积分有效期 90 天，且要**主动领**。领了不用也会过期，但领了之后做规则
> 优化时可以用上。领完记得确认一下到账。

## 第二步：开华为云 MaaS，解决赛题⑤「人工智能（必选）」

这是当前**最该优先做**的一件事，因为：
- 它不需要代金券
- 它填完三个环境变量，项目就真的用上华为云大模型了
- 赛题⑤是你自检里唯一的"进行中"硬门槛

### 为什么这个优先级高

创新赛明确写「综合运用**人工智能（必选）**」——不用 AI 直接不合规。
而 2026-10-05 你曾把 AI 全部删掉（为了项目纯粹性），这正好撞上这条硬要求。
现在要补回来，而且**必须用华为云的**（赛题要求"采用华为技术"）。

好消息：项目里 `modules/adjudicator.py` 已经把 MaaS 接口写好了，
**只要填 3 个环境变量就能生效，不用改一行代码。**

### 操作步骤（⚠️ 2026-10-21 实测修正，路径不是模型广场）

**先纠正一个坑**：MaaS 控制台首页有「免费开通」按钮，**你已经开通了，不要点它**。
判断依据：左侧已有完整菜单（在线推理、API Key 管理、订阅管理、用量统计），
这些只对已开通账号显示。

**免费额度也不在「模型广场」**，而是在更深一层：

```
区域：西南-贵阳一          ← ⚠️ 必须是这个区域，其他区域看不到免费服务
     ↓
左侧菜单：在线推理
     ↓
展开：预置服务 → 免费服务
     ↓
看到 DeepSeek-R1-32K 等免费模型 → 点「领取额度」→ 200 万免费 token
     ↓
点该模型旁的「调用说明」→ 记下 API 地址、模型名称
     ↓
左侧菜单：API Key 管理 → 创建 API Key
     ⚠️ API Key 只显示一次，当场复制保存，丢了只能重建
```

**拿到后填入 `.env`**（注意：`.env` 在项目根目录，你本地已有这个文件）：

```bash
MAAS_BASE_URL=调用说明里的API 地址
MAAS_API_KEY=上一步创建的API Key
MAAS_MODEL=调用说明里的模型名称
MAAS_TIMEOUT=60
```

**参考模板**：项目根目录新增了 `.env.example`，里面有全部环境变量的说明，
照着它填不会漏项。里面还有 RDS/Redis 的变量说明，等有资源了再填。

### 验证是否真的生效

```bash
# 在项目根目录执行（推荐这条，一次定位到具体环节）
.venv\Scripts\python.exe samples/check_ai_channel.py
```

这个脚本会分四步验：**① 变量是否读到 → ② 网络是否可达 → ③ 真实调用是否成功
→ ④ 降级路径是否可用**，并直接告诉你失败原因（额度没领 / 模型名不对 /
key 带空格 / 区域不对）。

只想快速看一眼的话用这条：

```bash
.venv\Scripts\python.exe -c "from modules import adjudicator as a; print('MaaS 可用:', a.is_available())"
```

- 输出 `MaaS 可用: True` → 变量齐了（但不保证能调通，以脚本第 3 步为准）
- 输出 `False` → 检查三项是否都填了、有没有多余空格、保存了没

然后启动界面：

```bash
.venv\Scripts\python.exe -m streamlit run main.py
```

**判据**：做一次扫描，在AI 研判区域看到：
- 顶部**不再**显示「本次研判由本地模板生成（未调用大模型）」
- 换成 MaaS 生成的研判文本

### Base URL 填到哪里为止（已查代码，不用猜）

`modules/adjudicator.py` 第 80 行的请求写法是：

```python
resp = requests.post(f"{MAAS_BASE_URL.rstrip('/')}/chat/completions", ...)
```

即代码会自己拼上 `/chat/completions`。所以：

| 控制台页面上给你的是 | 你填`MAAS_BASE_URL` 时 |
|---|---|
| `https://xxx.maas.myhuaweicloud.com/v1/chat/completions` | 填到 `/v1` → `https://xxx.maas.myhuaweicloud.com/v1` |
| `https://xxx.maas.myhuaweicloud.com/v1` | 原样填 |

**判断方法**：拿你拿到的 URL，如果末尾是 `/chat/completions` 就删掉这一段再填。

### ⚠️ 三个容易踩的坑

1. **模型名必须和申请额度的模型完全一致**。
   申请了 DeepSeek 却填 Qwen 的名字，会报模型不存在——这是最常见的失败原因。

2. **拿到 key 后先在控制台点一次「调用示例」测试**，确认额度有效。
   有些模型申请后需要等审核，不是立刻可用。

3. **填完必须重启 Streamlit**。环境变量在进程启动时读取，
   `Ctrl+C` 停掉再 `streamlit run main.py`，不然改了没效果。

## 第三步：RDS / Redis —— 两条不依赖代金券的路

赛题②③明确点名了 RDS 和 Redis。两条路：

### 路 A：免费试用额度（推荐现在试）

华为云有面向新用户的免费体验套餐，内容通常包含：
- 云数据库 RDS for MySQL：2 vCPU / 4 GB / 40 GB，约 1500 小时
- 分布式缓存 DCS for Redis：256 MB，2 个月

**领取路径**：

```
1. 登录 https://console.huaweicloud.com/
2. 顶部搜索框输入「免费试用」或「免费体验」→ 进活动页
3. 筛选带「免费试用」标签的产品
4. 点「立即领取」
5. 创建资源时务必选带「免费套餐」标记的规格
```

**⚠️ 两个必须注意的限制**：
1. **免费套餐只适用于按需计费（pay-per-use）**，包年包月要自己付钱。
2. 国内站与国际站的免费政策**不一样**，别照着国际站的教程做。

**先自查**：直接去 RDS 控制台看能不能用"免费套餐"标签创建，能建就说明有额度。

### 路 B：比赛代金券（等，但更稳）

报名审核通过后官方发代金券，能覆盖 RDS + Redis + ECS。
这条路更符合赛题意图（"华为云提供的免费资源"），推荐作为正式方案。

### 现在能做的准备（无论走哪条路）

`modules/store.py` 的存储抽象层已做好，本地模式能跑通全部功能。
资源到位后**只需在 `.env` 填连接信息，不用改代码**。

**判据（现在）**：`LocalStore` 可用、功能正常——说明抽象层没问题，
后续接云只是换数据源，不返工。

## 第四步：Redis 用途一定要写清楚（防答辩被问）

Redis 是赛题点名的服务，评委会问「你为什么需要 Redis」。
这个问题现在就得想好答案，因为你的项目里**已经有真实数据支撑**：

> **四源漏洞查询（OSV / NVD / GitHub / EPSS）首轮串行查询实测约 1035 秒**，
> 这是本项目最明显的性能瓶颈。Redis 用于两处：
> 1. **缓存四源查询结果**：同一 CVE 在重复扫描时不重复请求外部源，
>    直接命中缓存，实测可把重复扫描从秒级降到毫秒级。
> 2. **并发任务队列**：把四源查询拆成并发任务投递到队列，
>    用 Redis 做任务状态与结果暂存，配合已有的并发加速机制
>    （已实测 5.75× 加速、结果完全一致）。

这段话的意思是：**Redis 不是摆设，是用来解决一个你实测出来的真实瓶颈的。**
这比编一个"用 Redis 存会话"的答案强一百倍。
