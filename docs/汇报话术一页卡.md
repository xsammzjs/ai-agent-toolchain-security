# 汇报话术 · 一页卡（过几天组会用）

> **用法**：左边是「你说什么」，右边是「为什么这么说 / 被追问怎么办」。
> 背左边那三段就行，右边是保险。

## ⚠️ 讲的时候注意

1. **别把「卡住」说成求助**。你的定位是「代码已完成，只等资源到位」。
2. **数字要准**：32 条规则 / 8 类威胁 / 107 个样本 / 检出 100% / 误报 2.0% / 33ms / 151 条断言
3. **不要说**「全球首创」「业界首个」「国奖无同类实现」
4. **要说的**：可复现、CodeArts 三轮审计、1 条建议因会引入漏报被主动否决
5. **竞品表述**：说「我调研的信安国赛 45 个国奖一等奖里做 Agent 安全的 5 个全是单点检测，
   在这个调研范围内未发现做跨资产关联的实现」，说完补一句「这是我准备信安国赛时做的调研，
   Agent 安全方向整体还在早期」
