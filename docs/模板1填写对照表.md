## 三、作品介绍

### 3.1 方案的背景和价值（500字以内）

```text
AI Agent 正在以软件包的形式"安装"能力：Claude Code、Cursor、CodeArts
等工具的 Skill 机制允许 Agent 加载一个文件夹（SKILL.md 指令 + 可执行脚本）
并按其中指令行动。2026 年 ClawHavoc 事件中，1184 个恶意 Skill 被安装
24.7 万次；Snyk 审计显示 36.82% 的公开技能含提示注入。规模已超过 PyPI
早期蠕虫事件。

但现有工具（Snyk ToxicSkills、pip-audit、Trivy）全部是"单点检测"：
逐个文件判断"有没有风险"。而真实攻击是组合式的——Skill A 读取
~/.aws/credentials（单看只是读文件），Skill B 通过 webhook 外发数据
（单看只是网络请求），Skill C 让 A 调用 B。三个单点都判不严重，
串起来就是完整的凭据窃取链路。传统工具对此完全无解。

本项目把技能包、依赖包、MCP 工具统一建成资产图谱，用图路径搜索识别
跨资产的组合攻击链，同时保留传统依赖漏洞扫描作为证据来源之一。
这填补了"AI 时代新供应链"的检测空白，也让"AI 工具链"从概念变成
可核验的安全资产。
```

### 4.2 关键技术模块介绍

> 模板预置了「模块1 / 模块2 / 模块3」三行，**建议写 4 个**（多加一行，Word 里可以复制一行粘贴）。
> 官方要求「可…关键代码片段等文字、图片说明」。

```text
模块1  静态检测引擎（modules/skill_scanner.py）
32 条确定性正则规则覆盖 8 类威胁：提示注入、凭证窃取、数据外发、危险命令、
混淆载荷、持久化污染、供应链风险、隐藏字符注入。每条命中输出文件名 + 行号 +
命中原文 + 规则名 + 处置建议，结论可当场翻代码核验。全部规则离线执行，
单次扫描 33 毫秒。关键设计：跨行组合规则"凭证窃取完整链路"采用
"同文件内命中读凭据动作 AND 命中实际外发通道"的判定，避免把
"文档在描述怎么做"误当成"技能在执行什么"。

模块2  跨技能攻击链关联（modules/attack_chain.py）★核心创新
把每个技能的资产、行为、调用关系建成图，识别分散在多个技能中的完整
攻击链。例如：Skill A 读 ~/.aws/credentials、Skill B 通过 webhook 外发、
Skill C 让 A 调用 B——三者单独扫描均不判严重，串联后判定为最高危
"凭证窃取完整链路"。这是现有工具（Snyk ToxicSkills 等单点检测）不具备
的能力，也是本项目最主要的差异化价值。

模块3  资产图谱（modules/asset_graph.py）
将传统软件供应链（依赖包、SBOM）与 AI 供应链（Agent Skill、MCP 工具）
统一建模为同一张资产图，资产之间按引用、调用、依赖三种关系连边。
这使得"传统供应链风险"与"AI 供应链风险"能在同一个视图中回答
"哪些资产同时暴露于两类风险下"。

模块4  AI 研判层（modules/adjudicator.py）
基于已判定的检测证据做跨条汇总与修复优先级建议。为保证结论可信，
用 assert_ai_not_judging() 在代码层面禁止 AI 改写任何检测结论；
未配置大模型时自动降级为本地模板，并在界面明示"未调用大模型"，
不做能力伪装。
```
